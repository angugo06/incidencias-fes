# Glosario

| Término | Significado |
|---|---|
| Incidencia | Reporte de un problema de infraestructura en un lugar de la facultad |
| Folio | Identificador legible `INC-AAAA-NNNN` |
| Ubicación | Lugar del problema (catálogo) |
| Categoría | Tipo de problema: eléctrica, audiovisual, mobiliario, limpieza, otra |
| Responsable | Persona de mantenimiento a la que se asigna |
| Estado | `nueva`, `asignada`, `en_proceso`, `resuelta` |
| Transición | Cambio permitido de un estado a otro |
| Seguimiento | Línea de tiempo de eventos de una incidencia |
| Evento | Entrada del seguimiento: registro, asignación, estado o comentario |
| Historia (HU) | Requisito desde el punto de vista del usuario; HT = historia técnica |
| Sprint | Iteración de 3 días hábiles (7 h productivas por día, 20 h comprometidas) |
| Punto | Unidad de esfuerzo; 1 punto = 2 horas |
